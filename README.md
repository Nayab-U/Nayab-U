### HELIOS | Independent ICU trajectories, clinical measurements, and outcomes study
A separate end-to-end, pre-registered study of 11,888 adult ICU stays from the PhysioNet 2012 challenge data. HELIOS tests whether early vital-sign and laboratory trajectories add predictive information beyond admission data and the latest measurements.

- A tuned 24-hour gradient-boosting model reached AUROC 0.844 on a locked test set; the SAPS-I score reached 0.657 in the project comparison.
- The central finding is nuanced: updated measurements improved performance, but trajectory features did not pass the study's pre-defined rule for meaningful added value.
- Includes a reproducible Python pipeline, pandas and DuckDB SQL cross-checks, data validation, leakage safeguards, model evaluation, automated tests, and a Streamlit evidence dashboard.

[Explore the HELIOS study](https://github.com/Nayab-U/Capstone-project)

*Retrospective research prototype using de-identified data. Not for clinical use or medical decision-making. HELIOS is separate from the neuefische RWE capstone.*
